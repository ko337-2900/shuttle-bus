# シティハウス小金井公園 シャトルバス

シティハウス小金井公園の入居者向けシャトルバスの時刻表とカウントダウン表示アプリです。

🚀 **[今すぐ使う →](https://ko337-2900.github.io/shuttle-bus/index.html)**

## 概要

このアプリは以下の機能を提供します：

- **次のバス表示** - リアルタイムのカウントダウン表示
- **時刻表表示** - 3つの停留所の時刻表を確認
- **設定画面** - 乗車場所の設定や時間帯別の自動切り替え

## 特徴

- **PWA対応** - iOSやAndroidのホーム画面に追加可能
- **オフライン対応** - Service Workerで動作
- **レスポンシブデザイン** - スマートフォン最適化
- **ダークモード対応** - Light/Dark両モード対応
- **リアルタイム更新** - 毎秒カウントダウン更新
- **フレームワーク不要** - Vanilla JavaScript で軽量動作

## ファイル説明

### `index.html`
メインのHTMLファイル。以下の機能を含みます：
- ヘッダー表示（アプリ名、現在の停留所）
- 次のバス カウントダウンカード（分・秒表示、プログレスバー付き）
- 時刻表タブ（停留所選択可能）
- 設定タブ（乗車場所設定、時間帯設定）
- スライド型UI（タブ切替）

### `timetable.json`
バス時刻データ：
- 3停留所の時刻表
  - C棟エントランス前
  - シャトルバスステーション前
  - 武蔵小金井駅付近
- 平日ダイヤ（月〜金）
- 祝日・特別閉業日リスト
- ☆印は2号車を示す

### `manifest.json`
PWA設定：
- アプリ名・説明文
- スタンドアロン表示設定
- アイコン定義
- テーマカラー設定

### `app.json`
アプリメタデータ：
```json
{
  "name": "シティハウス小金井公園 シャトルバス",
  "short_name": "シャトルバス",
  "version": "Ver. 0.0.3",
  "build_date": "2026-06-27",
  "copyright": "© 2026 ooisan"
}
```
バージョンアップ時はこのファイルだけ変更。

### `sw.js`
Service Worker。オフライン対応と効率的なキャッシング。

## クイックスタート

### 1. アプリにアクセス
[ここをクリック](https://ko337-2900.github.io/shuttle-bus/index.html) または QRコードでアクセス

### 2. ホーム画面に追加（推奨）
**iPhone の場合：**
1. Safari で上記リンクを開く
2. 下部の共有ボタン → 「ホーム画面に追加」
3. ホーム画面に「シャトルバス」が追加される

**Android の場合：**
1. Chrome または別ブラウザで上記リンクを開く
2. メニュー → 「アプリをインストール」 または 「ホーム画面に追加」
3. 確認画面で「インストール」をタップ

### 3. 乗車場所を設定
初回起動時に「設定」タブで乗車場所を選択
- **時間帯で自動** - 朝と夕方で自動切り替え
- **手動で固定** - 常に同じ場所を表示
- **現在地** - GPS機能を使用

### 4. カウントダウンを確認
トップの「次のバス」タブで、リアルタイムのカウントダウンが表示されます

## 設定

### 乗車場所の決め方

#### 時間帯で自動
朝と夕方で異なる停留所を自動で切り替え
- 朝の停留所：切替時刻より前
- 夕方の停留所：切替時刻以降

#### 手動で固定
常に同じ停留所を表示

#### 現在地
GPS機能を使用（要許可）

## 運行日

- **平日**（月〜金）：フル運行
- **土日祝日**：運休
- **夏季休暇**：3日間運休
- **年末年始**：運休
- **特別閉業日**：2026/8/13-15、12/29-31、2027/1/2-3 など

## トラブルシューティング

### カウントダウンが表示されない
- ブラウザをリロード（F5 または ⌘+R）
- Service Worker のキャッシュをクリア：設定 → キャッシュ削除 → 再読み込み

### 時刻が古い
- 設定タブで乗車場所を再選択
- ブラウザのキャッシュをクリア

### PWAがインストールできない
- サポートブラウザを確認（Chrome / Edge / Safari 15+ / Firefox）
- HTTPS接続を確認（http:// ではなく https:// か確認）
- 別のブラウザを試す

### 位置情報が使用できない
- ブラウザの位置情報許可を確認
- 設定アプリから位置情報をONにする
- プライベート/シークレットモードを終了して試す

## 時刻表の更新

時刻が変更された場合、`timetable.json`を編集して PR を送ってください。

### 更新手順
1. `timetable.json` の対象時刻を編集
2. `_updated` フィールドを現在の日付に更新
3. PR を作成（変更内容を明記）

### バージョンアップ手順
1. `app.json` の `version` を更新（例：Ver. 0.0.3 → Ver. 0.0.4）
2. `build_date` を現在の日付に更新
3. 新しいバージョンのフォルダを作成（例：`20260701/`）
4. Git にコミット
